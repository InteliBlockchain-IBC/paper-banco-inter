# artigo

`artigo-alpha.tex` (e o PDF compilado) é **só uma versão base** do artigo, escrita em 22/10/2026
com os resultados das três testnets.

**Ele não foi usado no artigo final.** O artigo final foi escrito à parte, fora deste repositório.
Este arquivo fica apenas como registro do primeiro rascunho, e o texto dele pode divergir do
artigo final.

Os números citados aqui vêm de [`../pesquisa/3-resultados/resultados.md`](../pesquisa/3-resultados/resultados.md).
Para saber como os experimentos foram feitos, veja [`../benchmark/README.md`](../benchmark/README.md),
e não este arquivo.

Para compilar, dentro desta pasta: `latexmk -pdf artigo-alpha.tex`.
